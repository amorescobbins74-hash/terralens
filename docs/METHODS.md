# 方法与边界

## 为什么它与传统地图展示不同

地图只是结果界面。本项目的主要技术工作是浏览器内完整的数据处理链：STAC 查询、COG 分块读取、后台计算、坐标一致性、质量掩膜与证据溯源。NDVI / NBR 是成熟指数，不能因为使用新架构就把指数差分称为新的 AI 算法。

## 数据限制

1. 公共 Earth Search API 无可用性保证。实时读取需要能访问 Earth Search 和 Sentinel COG S3，并且服务器支持 CORS 与 HTTP Range。
2. 整景云量不等于研究区云量。即使云量很低，也可能刚好遮住研究区。页面单独显示两期共同有效覆盖，低于 50% 时提示局限。
3. 保守质量策略只保留 SCL 4、5、6。较暗烧毁地表可能被分类为 2，因而排除；统计不代表完整烧毁面积。烟雾和误分类也无法完全消除。
4. 两期时相差异可能含季节、含水量、太阳高度、地形阴影、积雪等影响。指数下降仅是待复核线索。
5. 60 m 是探索用抽样格网。没有执行空间均值聚合、误差校准、亚像元配准、面积精度验证或灾损类别训练。
6. 仅支持同一 WGS84 UTM 分区、北向上且网格兼容、均完整覆盖研究区的两期影像。不会悄悄重投影或用缺失影像拼凑结果。
7. MapLibre 的影像四角定位是小区域可视化近似；导出每个网格带顶点则逐点从 UTM 转换为 WGS84。地图截图不作为测绘结果。
8. 为控制浏览器内存，每边最多 320 个 60 m 网格。目录最多返回前 100 景，存在后续页时要求缩小日期范围。

## 性能与取消

波段按顺序读取，避免一次并发加载整套全分辨率波段。每个 Range 请求最多 3 次尝试，每次 25 秒；在线分析总超时 180 秒，点击取消会直接结束 Worker。超时或失败保留最后成功结果，并显示错误，不静默回退到“成功”样例。

初次下载地图代码比普通网页大。离线使用是指页面资源加载后，内置数据不需访问第三方影像服务；不是 PWA，也不保证未打开过的页面能在断网状态首次加载。

## 尚未实现

- Prithvi / SAM / DINO 等模型推理、自然语言 GIS Agent；
- 多时相统计检验、机器学习变化分类与验证集精度评估；
- 多用户项目持久化、协同审阅、自动监控任务；
- 生产 SLA、跨浏览器验收和无障碍完整审计。

后续要接基础模型，应增加真实推理适配器、模型版本 / 权重许可记录、有效像元输入约束和对照数据验证，而不是用阈值处理冒充 AI。
